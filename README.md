# Api Integration Specialist

## Overview

This repository contains a Claude skill for api integration specialist. It provides a structured workflow and practical guidance for handling API-related tasks with attention to reliability and security.

## Capabilities

- Defines the skill's purpose and scope.
- Provides repeatable instructions for relevant workflows.
- Covers planning, execution, and validation considerations.
- Includes original supporting resources where supplied.

## Repository Structure

```text
SKILL.md
```

## Requirements

- A Claude-compatible environment with skill support.
- A clearly defined API, application, or authorized test environment.
- Appropriate tools and permissions for the intended work.

## Getting Started

1. Read `SKILL.md` and note its scope and constraints.
2. Install the skill in your Claude environment's supported skills directory.
3. Provide the API context, objectives, and relevant technical details.
4. Follow the documented workflow.
5. Validate findings and proposed changes before applying them.

## Safety and Validation

Perform security testing only against systems you own or are explicitly authorized to assess. Use non-production environments where possible, avoid destructive tests without approval, and document findings with reproducible evidence.
